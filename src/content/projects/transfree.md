## About Transfree

Transfree is a File Transfer System, built for the police in my schools project week.
The main focus was building secure file transfers that are actually production-ready.

## Features
- Secure file uploads & transfers
- User authentication 
- Integrity Checks (Creating a hash on upload, and download to check if nothing has changed)
- Logging for admins

## Security

The system was pentested by an actual officer, it got tested against real exploits and weak points.
