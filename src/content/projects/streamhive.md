## About Streamhive

Streamhive is a Youtube clone made in PHP, SCSS, JS & MySQL.

The main focus of Streamhive was understanding OOP PHP coding.

## Features

- Video uploads
- Like & comment system
- User authentication
- Custom video player
- Categories
- Responsive UI
- Google Login
- Captcha
